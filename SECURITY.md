# Security Policy

MOONWITNESS IDE is an evolving desktop application based on the Lapce codebase. We appreciate responsible reports that help protect users and contributors.

## Supported versions

Security fixes are handled on a best-effort basis for the current development branch. Published release support will be documented when a release and maintenance policy are established.

## Reporting a vulnerability

Please do not publish an unpatched vulnerability, exploit, credentials, or sensitive user data in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow. Otherwise, contact the repository maintainer through the maintainer profile linked from this repository and request a private disclosure channel.

Include, where safe:

- A concise description and potential impact.
- Affected version, commit, platform, and configuration.
- Reproduction steps or a proof of concept that does not expose real user data.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Do not access, modify, or retain data that does not belong to you while investigating.

## Scope and limitations

This policy does not promise a response time, bounty, or support for any particular release. MOONWITNESS IDE's security posture must be assessed from the exact source revision and build under review; branding or roadmap statements are not security guarantees.
